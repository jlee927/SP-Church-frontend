
# Church Website (Frontend)

This is the frontend portion of the Church Website, designed to provide dynamic content for a local church organization. The site features a sermon archive, event announcements, and a comment section, allowing the community to stay informed and engaged.

## Features
- **Sermon Archive:** Browse past sermons with audio and video support.
- **Event Announcements:** Stay updated with upcoming events and church activities.
- **Comment Section:** Engage with the church community by commenting on sermons and posts.
  
## Setup

To run the frontend locally, follow these steps:

1. Clone this repository:
  git clone https://github.com/jlee927/SP-Church-frontend

   
2. Install dependencies:
   cd SP-Church-frontned
   cd client
   npm install

4. Start the development server:
   npm run dev

The website should now be running on `http://localhost:5173`.
